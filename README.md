# Telegram-магазин одноразовых цифровых товаров

aiogram 3 · PostgreSQL (asyncpg) · оплата Telegram Stars (XTR) · RU / UK / EN

## Запуск
```bash
cp .env.example .env          # заполните BOT_TOKEN, DATABASE_URL, ADMIN_IDS
pip install -r requirements.txt
python main.py                # схема БД создаётся автоматически
# или: docker compose up -d --build
```
Секреты (`BOT_TOKEN`, `DATABASE_URL`, `ADMIN_IDS`) берутся только из переменных окружения.

|---|---|---|
| `/start`, `/menu` | все | приветствие и главное меню |

## Как устроена защита от двойной продажи
1. **Резервирование** — `UPDATE products … WHERE свободен` (атомарно) на время оплаты (по умолчанию 5 минут, настраивается). Просроченные резервы освобождаются фоновой задачей.
2. **Финализация в одной транзакции** — `SELECT … FOR UPDATE` сначала по пользователю, затем по товару (единый порядок блокировок, без дедлоков). Проверяются статус товара, резерв, баланс и цена.
3. **Уникальный частичный индекс** `purchases(product_id) WHERE status='paid'` — даже при ошибке в коде вторая оплаченная покупка того же товара невозможна.
4. **Идемпотентность платежей** — `UNIQUE(transactions.charge_id)` + проверка в транзакции: повторный `successful_payment` ничего не выдаёт и не зачисляет повторно.
5. **Если оплатили, а товар уже продан/удалён** — Stars автоматически зачисляются на внутренний баланс (транзакция `refund_credit`), администратор получает уведомление. При желании можно вернуть Stars через `bot.refund_star_payment`.
6. `pre_checkout_query` перепроверяет товар, цену и резерв.

Финансовые записи (`transactions`, `purchases`) не удаляются; удаление товара — «мягкое» (`status='deleted'`), история покупок сохраняется. Данные покупки отдаются только владельцу (проверка `user_id` на сервере).

## Premium Emoji и шаблоны
* Редактор сообщений (`/adm → 📝 Сообщения`) сохраняет текст, **Telegram entities (включая custom_emoji)**, фото, GIF и inline-кнопки.
* Переменные `{first_name}`, `{price}`, `{product_data}` … подставляются с пересчётом UTF-16 offset/length у entities — Premium Emoji не «съезжают». `{product_data}` выделяется как `code` (копируется нажатием).
* Правки сообщений действуют для всех языков; тексты кнопок и системные сообщения переводятся (`texts.py`).
* **Важно:** Telegram может ограничивать отправку custom emoji ботами (по документации — например, требуется юзернейм бота, купленный на Fragment). Если Telegram отклоняет запрос, бот автоматически повторяет отправку с обычными emoji (чтобы пользователь всё равно получил сообщение). Проверьте актуальные правила Bot API.
* Чтобы вставить Premium Emoji в сообщение, админ должен иметь Telegram Premium.

## Структура
```
main.py            запуск, middleware, фоновые задачи
config.py          переменные окружения
db.py / schema.sql PostgreSQL: схема и все транзакционные операции
tpl.py             шаблонизатор переменных + entities, парсер кнопок
ui.py              отправка сообщений (медиа, entities, fallback)
texts.py           переводы, шаблоны по умолчанию, список переменных
user.py            каталог, покупка, баланс, избранное, язык, промокоды
payments.py        Stars: pre_checkout / successful_payment
delivery.py        выдача товара, уведомления админам
admin.py           /adm: товары, анкета, цены, статистика, пользователи, промокоды, настройки
admin_content.py   редактор сообщений и /bd
broadcast.py       очередь рассылки (≈20 msg/s, RetryAfter, пометка заблокировавших)
```
Расширение: новая категория — через админку; новый способ оплаты — отдельный модуль рядом с `payments.py` и вызов `db.finalize_*`; новый тип товара — поле `kind` в `products` и своя ветка в `delivery.py`.

## Эксплуатация
* FSM хранится в памяти (`MemoryStorage`) — при рестарте незавершённые анкеты сбрасываются. Для нескольких инстансов/вебхуков используйте `RedisStorage`.
* Рассылки и уведомления о новых товарах идут фоновыми задачами; параллельно выполняется только одна рассылка.
* Бонус за пополнение, поддержка (`@cryptcursed` по умолчанию), название магазина, резерв и авто-уведомления меняются в `/adm → ⚙️ Настройки`.
* Выплата заработанных Stars — через Telegram/Fragment по их правилам (есть период удержания).

## Раздел «Сообщения» (`/adm → 📝 Сообщения`)
* **Шаблоны и страницы разделов:** приветствие, главное меню, каталог, карточка товара, оплата, покупка, выдача, ошибка оплаты, промокод, новые товары, поддержка, страница баланса, список и карточка покупки, избранное, страница уведомлений, проблема с покупкой. Каждое поддерживает текст, фото, GIF, Premium Emoji, переменные и URL-кнопки, есть предпросмотр и сброс к стандарту.
* **🔘 Тексты кнопок:** выбираете раздел → кнопку → язык (или «Все языки») и вводите новую надпись. Меняется только текст, действие кнопки не меняется. Premium Emoji в кнопках Telegram не поддерживает, допустимы обычные emoji.
